Introducción y Configuración del Sistema de Ventanas en Blender

Después de iniciar Blender y cerrar el Splash Screen (pantalla de inicio), la ventana principal debería verse similar a la imagen de abajo.

La interfaz predeterminada de Blender está separada en tres partes principales:

  • La barra superior (Topbar): En la parte superior, contiene el menú principal, que se utiliza para guardar, importar y exportar archivos, y renderizar, entre otras funciones.
  • Las áreas (Areas): En el medio, que conforman el espacio de trabajo principal (Viewport, Outliner, Propiedades).
  • La barra de estado (Status Bar): En la parte inferior, que muestra sugerencias de atajos de teclado y estadísticas relevantes (conteo de polígonos, memoria, etc.).

Layout predeterminado de Blender. Barra superior (azul), Áreas (verde) y Barra de estado (rojo).

Personalización del Entorno de Trabajo

1. Menús y Barras de Herramientas

A diferencia de Maya, Blender mantiene una interfaz limpia sin ventanas flotantes. Para menús personalizados se usa el menú Quick Favorites.

  • Añadir a favoritos: Clic derecho sobre cualquier herramienta > Add to Quick Favorites. Se accede con la tecla Q.
  • Barras de herramientas: La Toolbar (izquierda) se alterna con T y el Sidebar (derecha) se alterna con N.

2. Configuración de Atajos de Teclado

Blender permite personalizar atajos desde Edit > Preferences > Keymap.

  • Asignación: Busca un comando por nombre o tecla y reemplázalo presionando tu nueva combinación.
  • Exportar/Importar: Usa los botones en la parte superior derecha de esta ventana para guardar un archivo .py con tus configuraciones y llevarlas a otros equipos.

3. Layouts y Paneles (Áreas)

  • Dividir (Split): Arrastra desde cualquier esquina del panel (cuando el cursor se vuelva una cruz +) hacia el centro.
  • Unir (Join): Arrastra desde la esquina hacia el panel que deseas cerrar.
  • Cambiar editor: Usa el icono en la esquina superior izquierda de cada panel para cambiarlo a Visor 3D, Editor de Nodos, etc.

4. Shelves Personalizados

Blender sustituye los "Shelves" de iconos de Maya con el Asset Browser.

  • Puedes marcar objetos o materiales en el Outliner haciendo clic derecho y seleccionando Mark as Asset. Luego, abre un panel de Asset Browser para arrastrarlos rápidamente a la escena.

5. Preferencias de Usuario y Temas

  • Temas de color: Para evitar fatiga visual o adaptar colores, ve a Edit > Preferences > Themes. Puedes elegir presets o editar elementos individuales.
  • Accesibilidad y Rendimiento: En la pestaña System puedes configurar tu GPU (OptiX/CUDA) y en Interface puedes ajustar la escala de resolución.

6. Scripts y Workspaces

  • Integración de Scripts (Add-ons): Se instalan desde Edit > Preferences > Add-ons > Install... seleccionando el archivo .zip.
  • Espacios de Trabajo (Workspaces): Son las pestañas superiores (Modeling, Sculpting, Animation). Puedes crear nuevas dándole al botón +. Para guardar todo este layout como predeterminado al abrir el programa, ve a File > Defaults > Save Startup File.
