Introducción al sistema de ventanas

Después de iniciar Blender y cerrar el Splash screen (pantalla de inicio), la ventana de Blender debe ser similar a la imagen de abajo.

La interfaz de Blender está separada en tres partes principales:

  • La barra superior (Topbar): En la parte más alta, consiste en el menú principal, que se usa para guardar, importar y exportar archivos, configurar ajustes y renderizar, entre otras funciones.
  • Las Áreas (Areas): En el medio, que son el espacio de trabajo principal.
  • La Barra de estado (Status Bar): En la parte inferior, que muestra sugerencias de atajos y estadísticas relevantes.

Layout predeterminado de la pantalla de Blender. Barra superior (azul), Áreas (verde) y Barra de estado (rojo).

Personalización y Configuración

1. Personalización del Menú y Barras de Herramientas

Menús de la Barra Superior (Topbar)

La barra superior contiene opciones esenciales para la gestión del proyecto (Menú Blender, File, Edit, Render y Window).

Regiones y Barras de Herramientas

Cada editor en Blender se divide en Regiones. Las barras de herramientas más importantes para la personalización y acceso rápido son:

  • Toolbar (Barra de herramientas): Ubicada en el lado izquierdo del área del editor, contiene herramientas interactivas. Puedes añadir o eliminar su visibilidad presionando T.
  • Sidebar (Panel lateral): Ubicada en el lado derecho, contiene paneles con configuraciones de los objetos. Puedes alternar su visibilidad con N.

2. Layouts y Paneles de Interfaz (Áreas)

La ventana de Blender está dividida en rectángulos llamados Áreas. Blender permite manipular de forma interactiva el tamaño y la ubicación de las áreas para crear layouts personalizados que maximicen el espacio y la eficiencia:

  • Dividir (Splitting) paneles: Coloca el cursor en la esquina de un área hasta que cambie a una cruz (+). Arrastra hacia la izquierda/derecha o arriba/abajo para abrir nuevas ventanas de trabajo.
  • Unir (Joining) paneles: Arrastrando desde la esquina de un área hacia el espacio de una segunda área, cerrará y unirá ambas.

3. Shelves Personalizados (Asset Shelf)

Blender utiliza el Asset Shelf de manera similar a los "shelves" de otras aplicaciones. Esta región permite organizar íconos, comandos y crear accesos rápidos a elementos específicos.

  • Organización y Pestañas: Los catálogos se pueden mostrar como pestañas individuales, haciendo que sea muy fácil filtrar un conjunto específico de herramientas o activos para un acceso rápido.

4. Uso de Scripts y Herramientas Personalizadas

En Blender, la integración de scripts y herramientas de terceros se maneja a través del sistema de Add-ons. Un complemento es básicamente un módulo de Python con requisitos adicionales (como el diccionario bl_info y las funciones de registro register()/unregister()) para que Blender pueda mostrarlo e integrarlo en la interfaz.

Instalación y ejecución: Para instalar scripts personalizados o descargados, el archivo debe guardarse con extensión .py y posteriormente instalarse desde Preferences ‣ Add-ons ‣ Install…. Una vez activo, el operador se puede buscar o integrar en menús personalizados.

5. Configuración de Atajos de Teclado

Blender hace un uso intensivo de los atajos de teclado para acelerar el trabajo. Estos se pueden personalizar detalladamente en el Keymap Editor dentro de las Preferencias.

  • Asignación: Puedes buscar herramientas frecuentes mediante filtros y asignarles atajos personalizados.
  • Importar/Exportar: La opción Import abre un explorador de archivos para seleccionar un archivo .py con un preset personalizado, mientras que Export guarda la configuración actual como un preset para compartirla.

6. Configuración del Entorno de Trabajo

Espacios de trabajo (Workspaces)

Este conjunto de pestañas se utiliza para crear y guardar Workspaces, que son diseños predefinidos de ventanas orientados a tareas particulares (modelado, animación, etc.).

Guardado automático y recuperación

Blender proporciona opciones integradas para recuperar archivos y evitar la pérdida de datos desde el menú File ‣ Recover:

  • Last Session: Carga el archivo quit.blend guardado automáticamente antes de salir.
  • Auto Save: Permite recuperar la versión más reciente guardada de forma automática en caso de un fallo del sistema.

7. Configuración de Preferencias de Usuario

Unidades de medida

El sistema de unidades para los controles de la interfaz se configura en el panel Properties ‣ Scene ‣ Units. Permite alternar entre el sistema Métrico (Metric) o Imperial, ajustar la escala y definir de forma independiente cómo se muestran las unidades de longitud, rotación, masa, tiempo y temperatura.

Temas de color y apariencia

Blender permite personalizar los colores de su interfaz para reducir la fatiga visual abriendo las Preferencias y seleccionando la pestaña Temas (Themes).
